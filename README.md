# Гроші ОК 💰

Проста програма для підрахунку щомісячних витрат. Потрібен лише Python 3 — без додаткових бібліотек.

## Запуск

```bash
python3 groshi_ok.py          # інтерактивне меню
```

## Команди

```bash
python3 groshi_ok.py add 250 Їжа "Продукти"          # додати витрату (сьогодні)
python3 groshi_ok.py add 1200 Комуналка --date 05.11.2026
python3 groshi_ok.py list                            # витрати за поточний місяць
python3 groshi_ok.py list 2026-10                    # за інший місяць
python3 groshi_ok.py report                          # звіт: категорії, %, середнє на день, бюджет
python3 groshi_ok.py budget 15000                    # встановити місячний бюджет
python3 groshi_ok.py delete 3                        # видалити витрату №3
python3 groshi_ok.py export                          # зберегти місяць у CSV (відкривається в Excel)
```

Категорії за замовчуванням: Їжа, Житло, Комуналка, Транспорт, Здоров'я, Одяг, Зв'язок, Розваги, Освіта, Інше (можна писати й свої).

Дані зберігаються у `groshi_ok.json` поруч із програмою.
